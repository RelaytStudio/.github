CRM and ERP implementation, system integration, and custom applications for web, mobile and Telegram.

## What we work with

- **CRM and ERP** &nbsp;·&nbsp; amoCRM, Bitrix24, MoySklad, Odoo, and whatever else is already in place
- **Telephony** &nbsp;·&nbsp; Asterisk, onlinePBX, Sipuni, UTel, call tracking into the deal card
- **Payments** &nbsp;·&nbsp; Payme, Click, Uzum, Stripe, and other gateways
- **Applications** &nbsp;·&nbsp; web, mobile, desktop, Telegram bots and Mini Apps

Most often TypeScript, Next.js, React Native, Node, Python and Postgres. The
stack is picked per project, not fixed.
